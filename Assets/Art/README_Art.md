# Art Resources Guide

## 폴더 구조 안내

현재 아트 리소스는 깃 충돌 방지 및 가독성 향상을 위해 **화면별(Screen) 폴더 구조**로 관리되고 있습니다.

```text
Assets/
  └── Art/
       ├── Screen2/            # 화면2 관련 리소스 (냉동고, 아이스크림, 도구 등)
       ├── Screen3/            # 화면3 관련 리소스 (포장, 뚜껑 등)
       └── (이전 파일들)       # 재매핑 완료 후 삭제 예정
```

> **⚠️ 주의 사항**
> 기존에 매핑된 이미지가 깨지는 것을 방지하기 위해 예전 파일들은 당분간 유지합니다. 
> 하지만 앞으로는 기존 파일들을 사용하지 않을 예정이므로, 각 담당자분들은 **반드시 `Screen` 폴더 내부의 새로운 파일로 재매핑**을 진행해 주시기 바랍니다.

---

## 폴더별 상세 에셋 설명

### Screen 2 (화면 2)
*   `iceCreamBins`: 냉동고 내부 아이스크림 리소스 (클릭 시 용기에 담기는 기능에 사용)
*   `iceCreamFlavorTexture/`
    *   `flavor_discs/`: 산코~록코의 담기 로직 변경을 위한 리소스
    *   `ikko_niko_flavor_overlays/`: 잇코, 니코용 아이스크림 리소스
    *   `IceCreamCup/`: 컵 리소스 (탑다운 뷰). *※ 잇코, 니코 리소스는 추후 수정될 가능성이 있습니다.*
*   `Tools/`: 도구함 관련 리소스. *※ 크기나 비율에 문제가 있다면 언제든 아트 담당자에게 알려주세요.*

### Screen 3 (화면 3)
포장(Packaging) 관련 화면 리소스입니다.

*   `lids/`: 산코~록코용 용기 뚜껑 리소스 
    *   *연출 가이드:* 포장 화면에서 쌓여있는 뚜껑을 클릭하면 뚜껑이 날아와서 덮히고, 열린(`opened`) 용기가 닫힌(`closed`) 용기로 변경되도록 구현 부탁드립니다. (잇코, 니코는 뚜껑이 없습니다.)
*   `packaging_opened`: 뚜껑이 **열려있는** 용기 리소스
*   `packaging_closed`: 뚜껑이 **닫혀있는** 용기 리소스
