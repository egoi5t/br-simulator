# BR 시뮬레이터

배스킨라빈스 컨셉의 1인용 아이스크림 매장 시뮬레이터.
30가지 맛 아이스크림을 손님 주문에 맞게 제공하는 아케이드형 타이쿤/시뮬레이션 게임.

> 판도라큐브 · **꼬꼬마** 팀 프로젝트

---

## 개발 환경

| 항목 | 값 |
|------|-----|
| 엔진 | **Unity 6.0 LTS (6000.0)** — 팀 전원 동일 버전 사용 |
| 플랫폼 | PC |
| 버전 관리 | Git + **Git LFS** |

### 처음 세팅하는 사람 (필독)

1. **Unity Hub**에서 `Unity 6.0 LTS (6000.0)`을 설치한다. (반드시 같은 버전 — 빌드 번호까지 동일하게)
2. 저장소를 클론하기 전에 로컬에 **Git LFS**를 설치한다.
   ```bash
   git lfs install
   ```
3. 저장소 클론:
   ```bash
   git clone https://github.com/<계정>/br-simulator.git
   ```
4. Unity에서 프로젝트를 열고, **Project Settings → Editor** 에서 아래를 확인한다.
   - Version Control → Mode: **Visible Meta Files**
   - Asset Serialization → Mode: **Force Text**

## 협업 규칙

- `main` 브랜치에 직접 push 금지 → **브랜치 + Pull Request**로 합친다.
- 브랜치 예시: `feature/order`(주문), `feature/craft`(제작), `feature/system`(진행·UI)
- **`Library/` 폴더는 절대 커밋하지 않는다.** (자동 생성 폴더, `.gitignore`에 포함)
- 커밋 메시지는 짧고 명확하게. 예) `주문 처리: 용기 선택 로직 추가`
- 큰 바이너리(이미지·사운드·모델)는 자동으로 **LFS**로 관리됨 (`.gitattributes` 참고).
